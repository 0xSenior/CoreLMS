# CoreLMS

CoreLMS is a secure, luxury-tier learning platform built as a modular monorepo.

## Workspaces

- `apps/web`: Next.js App Router frontend with TailwindCSS, GSAP, and a cyber-glassmorphism design system.
- `apps/api`: NestJS backend with a decoupled module layout, Prisma, validation, throttling, and security-first defaults.
- `packages/shared`: Shared TypeScript contracts and enums that can be consumed by both apps.
